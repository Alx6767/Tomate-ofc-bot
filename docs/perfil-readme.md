### 🍅 En qué ando

- **Tomate ofc bot** — bot de WhatsApp con más de 200 comandos en 16 categorías:
  economía, RPG, gacha, minijuegos jugables, IA y administración de grupos.
  Escrito desde cero, con plugins que se cargan solos.
- Pensado para correr en **Termux** sin compilar nada: la base de datos es un
  JSON y las descargas no dependen de un solo programa externo.
